# ENCOUNTR v20 — Clean GitHub Pages Prototype

This version uses 12 individually normalized ENCOUNTR mobile-app assets.

## App asset standard
- 12 separate PNG files
- Exact canvas: 420 × 760 px
- Identical visible phone/content frame: 352 × 718 px
- Identical placement on canvas: x=34, y=21
- No collage is used as the website asset source

## Website
Static GitHub Pages-ready front end. The app screens are presentation assets only; no real authentication, bookings, payments, identity verification, messaging, location sharing or escrow are implemented.

## Files
- `index.html` — website
- `styles.css` — layout and styling
- `app.js` — demo interactions
- `assets/encountr-app-*.png` — 12 normalized app screens

Version: v21 — strict uniform app gallery sizing.
